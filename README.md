# HL2-Lambda-Locator-Helper

A simple C# console program that reads your HEX string and shows which stashes (lambdas) you missed in Half-Life 2. Helps you unlock the "Lambda Locator" achievement.

## How to use

1. [Download .NET 9.0+](https://dotnet.microsoft.com/en-us/download)
2. Go to the RELEASE page and download the file `HL2LambdaLocatorHelper.exe`. Run it.
3. Enter your hex string and get the result (For help, enter `?` in the program window)
